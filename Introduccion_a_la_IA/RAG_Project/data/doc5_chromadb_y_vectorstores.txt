BASES DE DATOS VECTORIALES Y CHROMADB

Las bases de datos vectoriales son sistemas de almacenamiento optimizados para guardar, indexar y recuperar datos no estructurados (textos, imágenes, audio) mediante sus representaciones matemáticas llamadas embeddings vectoriales.

Un embedding es un vector de números flotantes de alta dimensión (por ejemplo, 768 o 1536 dimensiones) que captura el significado semántico de un texto. Palabras, frases o párrafos con significados conceptualmente similares quedan representados como puntos muy cercanos dentro de este espacio vectorial multidimensional.

A diferencia de las bases de datos relacionales tradicionales que realizan búsquedas por coincidencias exactas de palabras clave (SQL/Full-Text Search), las bases de datos vectoriales ejecutan Búsqueda por Vecinos Más Cercanos (k-NN) evaluando métricas geométricas como:
- Similitud del Coseno: Mide el ángulo entre dos vectores.
- Distancia Euclidiana: Mide la distancia en línea recta entre dos puntos.
- Producto Escalar (Dot Product): Mide la magnitud y dirección compartida.

ChromaDB es una base de datos vectorial de código abierto altamente popular para construir aplicaciones RAG. Permite persistir los vectores y sus metadatos asociados (como el archivo de origen o número de página) directamente en el disco local del servidor.

Durante una consulta en un sistema RAG, ChromaDB compara el embedding de la pregunta con todos los fragmentos almacenados y devuelve de manera casi instantánea los k fragmentos con mayor puntuación de similitud semántica.
